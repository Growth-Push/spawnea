# Code of Conduct

## Our standard

Spawnea contributors are expected to keep project spaces professional, constructive, and welcoming.

Examples of expected behavior include:

- discussing ideas and code on their technical merits;
- giving actionable, respectful feedback;
- assuming good faith while still being precise about problems;
- respecting different backgrounds, experience levels, and viewpoints;
- accepting correction and taking responsibility for mistakes;
- keeping project discussions focused on the work.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, deliberate intimidation, doxxing, sexualized behavior, or sustained disruption of project spaces.

## Scope

This code applies to repository discussions, issues, pull requests, reviews, community spaces operated by the project, and situations where someone is representing Spawnea publicly.

## Enforcement

Project maintainers may edit or remove contributions that violate this code and may temporarily or permanently restrict participation when necessary.

Reports should be made privately to the project maintainers rather than posted publicly. Reports will be handled as confidentially as practical.

Maintainers are expected to apply these standards consistently and in good faith.
